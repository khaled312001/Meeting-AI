Installation

Windows

  1. Open the downloaded file.
  2. If Windows shows a warning, click More info, then Run anyway.
  3. The app opens when setup finishes. Sign in and start.

Mac

  1. Open the .dmg and drag the app into Applications.
  2. If macOS says the app is "damaged", run this in Terminal:xattr -cr "/Applications/Meeting AI.app"
  3. Open the app and allow microphone and screen recording access.
Not sure which Mac you have? Open the Apple menu → About This Mac. Chip means Apple Silicon; Processor … Intel means Intel.
